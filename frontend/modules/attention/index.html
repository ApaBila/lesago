Model III: Mekanisme Perhatian (Attention)

Dari Mana Konteks Berasal?

Model sebelumnya memproses data secara independen. Mekanisme perhatian memungkinkan model untuk mempertimbangkan hubungan antara kata-kata dalam sebuah kalimat, memberi bobot pada kata-kata yang paling relevan untuk memahami konteks setiap kata. Ini adalah inti dari model Transformer.

Proses ini dapat dirumuskan sebagai: $Attention(Q, K, V) = \text{softmax}(\frac{QK^T}{\sqrt{d_k}})V$. Klik sebuah kata di bawah untuk melihat perhitungannya.
